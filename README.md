# Student Attendance Management System
A web-based Student Attendance Management System developed using HTML5, CSS3, JavaScript, and Local Storage. The application enables efficient student record management, attendance tracking, and data storage directly in the browser through a simple and user-friendly interface.

Features

Student Information Management

Student Attendance Recording

Attendance Record Management

Data Storage Using Local Storage

User-Friendly Interface

Technologies Used

HTML5

CSS3

JavaScript

Browser Local Storage
